# 1.10.0

Cobblemon 1.8.0 coverage (Phase 16) + a `cobblemon` module library-quality audit and fix pass (Phase 17).

## Added

- `tms.TMManager` — query wrapper around Cobblemon's new `TechnicalMachines` registry, plus per-player `learn`/`unlearn`/`hasLearned`/`getLearnableTMs` via `TMMoveManager`.
- `PokemonPropertyManager.setAlpha`/`isAlpha` — Alpha Pokémon flag mutation/query.
- `spawning.HabitatManager` — query wrapper around the new `HabitatPools` registry.
- `spawning.HabitatBlockInterceptor` — hooks into habitat block spawn-activation and settings-save events.
- `BattleInterceptor.onBattleFlee` — notification hook for `BattleFleeAttemptEvent`.
- `npc.party.PartyCompositionManager` — query wrapper around `CobblemonPartyPools`/`CobblemonPartyCompositions`.
- `PartyBuilder.useComposition` — builds a datapack-driven `ComposedPoolPartyProvider` for NPC parties.

## Fixed

- `WildPokemonBuilder`'s IV/EV setters (`setIVs`/`setEVs`/`setFlawless`/`randomizeIVs`) mutated `Pokemon.ivs`/`evs` directly instead of Cobblemon's own `setIV`/`setEV`, skipping the max-HP recalculation those methods perform when the HP stat changes — the same bug class fixed once already for `PokemonPropertyManager`, reintroduced here. Every boss spawned via `.setFlawless()` was affected.
- `SwarmManager.activeSwarms` was a plain, non-thread-safe map mutated from both the main thread and an async scheduler task — switched to `ConcurrentHashMap`.
- `BossHpSynchronizer.tick()` was never called anywhere, so the boss-bar/HP-sync feature registered via `WildPokemonBuilder.setBossBar(...)` silently did nothing after spawn. Wired into `LuxCobblemon`'s main tick loop.
- `ApricornManager.onApricornHarvested` discarded its event subscription, unlike every other interceptor hook in the module — now returns `ObservableSubscription`.
- `PartyManager.transferToPC` duplicated `PCStorageManager.depositToPC` without enforcing the server's `preventCompletePartyDeposit` config guard. Now delegates to `PCStorageManager.depositToPC` internally.
- `HookManager` had no way to unregister a previously registered hook. Added `unregisterCatchHook`/`unregisterDefeatHook`/`unregisterLevelUpHook`/`unregisterEvolutionHook`/`unregisterEggHatchHook`.
- Replaced 37 raw `println` calls across 8 files in the `cobblemon` module with proper slf4j logging, matching the existing `LootManager` precedent. Along the way, fixed `LuxAIInjector`'s brain-update warning, which used an escaped `\${entity.id}` inside a regular string literal and printed the literal text instead of the actual entity id.
- `RewardExtensions.giveItem` silently no-op'd on a malformed item id string while logging a warning for the adjacent unknown-id case — now logs for both.
