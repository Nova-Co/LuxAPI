# 1.2.5

Phase 13 module-fixes-and-cleanup pass.

## Fixed

- `bukkit`'s shaded jar was published as `LuxEcoCore`, the same artifact name `economy` (the real standalone `LuxEcoCore` Vault-bridge plugin) uses — `bukkit` is a library module with no `plugin.yml` of its own, so its `shadowJar`/`jar` output is now named `LuxAPI-Bukkit` instead.
- `LuxConfig.reload()` used to copy every declared field except the literal `configFile` from a freshly-loaded instance onto `this`, which would have silently clobbered any future non-persisted/computed field a subclass adds. It now skips any field marked `@Transient`/JVM `transient`, not just `configFile` by name.
- `LootManager.distribute()` silently no-op'd when called with an unregistered `lootId`. It now logs a warning so a bad ID doesn't fail invisibly.

## Removed

- The `discord` module stub (`include("discord")` in `settings.gradle.kts`). It never had real content — its only committed file was IntelliJ's default `Main.java` template from the initial commit — and `commons` already ships the real `DiscordWebHook`/`DiscordEmbed` API.

## Docs

- `README.md` module table, version references, and project-status section synced against the actual current phase/version state.
- Added this file and the root `CHANGELOG.md`.
